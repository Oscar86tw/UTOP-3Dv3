UTOP-3Dv3 V1.7.10 Deployment Consistency Hotfix

這版不是功能擴充，專門處理 GitHub Pages 混合版本載入。

1. index.html 的標題、Boot VERSION、app.js / app.css query 全部同步 V1.7.10。
2. 所有 ES Module query 統一 V1.7.10。
3. 新增 build-info.json，啟動時用 no-store 讀取。
4. Index / Runtime / Manifest 任一版本不同，就直接顯示部署版本不一致。

修改說明事項／後續追蹤
- 部署後診斷網址應全部看到 v=1.7.10。
- 若仍看到 v=1.7.7，代表 GitHub Pages 或瀏覽器仍提供舊部署，不是 Runtime 功能錯誤。
