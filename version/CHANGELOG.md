# UTOP-3Dv3 CHANGELOG

## V0.2.0 — 2026-08-09
- 新增 Three.js/WebGL 3D 車道核心。
- 新增真正 3D 車輛、柵欄機、地感、ETAG、控制箱、警衛室。
- 車輛支援 W/A/S/D、方向鍵與手機按鈕。
- 車輛進入地感區自動觸發 Loop → DI1 → Relay → DO1 → Barrier。
- 新增手機拖曳旋轉、雙指縮放。
- 新增跟車視角、記錄視野、下一視野。
- 新增 DI/DO 3D 曲線與感應區顯示/隱藏。
- 模組快捷鍵 G / Shift+G / L / E / V 可直接控制 3D。
- Three.js 使用動態 CDN 載入；失敗時僅 3D 頁降級，不影響其他頁。
- 程式新增 core-3d-01 獨立資料夾。
- 單一資料夾仍維持不超過 90 個檔案。
