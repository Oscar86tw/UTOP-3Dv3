# V1.4.6

- 修正車輛方向：W 前進、S 後退、A 左轉、D 右轉。
- 車輛新增車頭、擋風玻璃、前燈與尾燈，方向可直接辨識。
- 修正 3D 選取框：不再把 UHF 感應 Cone、名稱 Sprite、Timer Sprite 納入設備 Bounding Box。
- 修正設備名稱牌高度計算，避免名稱牌本身反覆放大 Bounding Box。
- 縮小 XYZ / RX/RY/RZ Gizmo 顯示尺寸，避免遮住場景。
- 預設僅顯示 1F，B1/B2 預設隱藏。
- 入口/出口設備重新對準雙車道中心與外側安裝位置。
- Controller 改為有立柱與控制箱；Camera 改為有安裝桿與支架。
- 快取參數更新至 1.4.6。
