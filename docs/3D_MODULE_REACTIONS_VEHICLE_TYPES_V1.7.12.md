# V1.7.12 3D Module Reactions & Vehicle Types

## 3D 模組反應
所有模組都必須在 Runtime 狀態變化時具備可視反應。優先使用設備專屬部件，例如柵欄機桿、鐵捲門、紅綠燈、讀卡機 LED、攝影機狀態、倒數面板；其餘模組使用通用 Activity LED 作為保底。

## 地感
Garrison LK-109 單線圈車輛檢知器官方規格包含電源、偵測狀態與故障 LED 指示，並有兩迴路獨立繼電器輸出。因此 3D 地感檢知器顯示 POWER / DETECT / PULSE / FAULT 狀態。

地面感應線圈 LK-109L 本身是埋設感應線，因此模擬器額外使用工程視覺化燈光來表達偵測狀態：待機低亮度、偵測時亮綠並顯示光暈。此燈光是模擬提示，不代表實體 LK-109L 線圈會發光。

## 車種
Simulator 新增：
- car：汽車
- motorcycle：機車

兩種車體各自使用不同 3D 幾何與 Bounding Box。地感觸發採車體 Box3 與線圈區域 Box3 相交判斷。

## 操作方向
不得改變：
- W / ↑：沿車頭前進
- S / ↓：後退
- A / ←：左轉
- D / →：右轉
