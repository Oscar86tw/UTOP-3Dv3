# V1.7.13 Vehicle Lane & Loop Sensitivity

## 車道類型
- mixed：混合車道
- car：汽車道
- motorcycle：機車道

車道類型只負責交通規則提示，不會改變地感的物理偵測結果。

## 地感判斷
- 以車體 THREE.Box3 與地感線圈範圍的重疊面積比例判斷。
- 汽車門檻較低；機車因金屬量與投影面積較小，模擬門檻較高。
- 地感檢知器 sensitivity 1～10 級會降低或提高觸發門檻。
- 車輛已進入線圈但未達門檻時，狀態顯示 WEAK / MISS，3D 顯示「感應不足」。

## 視覺狀態
- 成功偵測：線圈綠色高亮、DETECT LED 亮。
- 感應不足：線圈/檢知器顯示警示狀態。
- 離開線圈：恢復待機。

此功能為工程模擬，不代表特定實機在所有施工條件下的固定觸發距離。
