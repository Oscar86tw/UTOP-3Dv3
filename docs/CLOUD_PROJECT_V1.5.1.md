# Google 雲端專案 V1.5.1

## 架構
- 前端：GitHub Pages / Netlify / 一般靜態網頁。
- API：Google Apps Script Web App。
- 專案檔：Google Drive `.utop3d.json`。
- 索引：Google Sheet `UTOP3D_Projects`。

## 功能
- 測試連線
- 重新整理雲端專案清單
- 儲存
- 另存新專案
- 開啟
- 刪除（移到 Google Drive 垃圾桶）
- 匯入舊版瀏覽器 localStorage 專案，再存到 Google

## Apps Script
請參考 `google-apps-script/README.md`。
