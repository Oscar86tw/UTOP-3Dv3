# UTOP-3Dv3 V0.9.0 Wiring Card Builder

這一版把接線圖改成更直覺的 **卡片式模組接線**。

## 本版重點
- 每個模組都顯示成卡片
- 每張卡片直接顯示端子群組
- 可以直接點選來源端子，再點另一個模組的目標端子建立連線
- 建立的接線會同步進 `state.connections`
- 接線會同步在 3D 裡顯示
- 可從接線卡片直接跳到 3D Focus 顯示

## 使用方式
1. 進入「工程」頁面
2. 在卡片式接線圖中點一個模組端子作為來源
3. 再點另一個模組的端子作為目標
4. 系統會自動建立 Connection
5. 點「在 3D 顯示全部接線」或單一模組的「3D顯示」即可查看
